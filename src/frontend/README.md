# Hospital Smart Portal – Final Frontend

واجهة المريض النهائية، مربوطة ببيئة Production الخاصة بـ n8n.

## التشغيل

افتحي `index.html` عبر Live Server، ثم استخدمي رقم هوية اختبار موجود في قاعدة البيانات مثل:

`012345678`

## API Base URL

`https://sprang-hesitancy-unwanted.ngrok-free.dev/webhook`

## الوظائف

- تسجيل دخول المريض عبر رقم الهوية.
- تحميل جميع العيادات النشطة.
- البحث داخل العيادات.
- عرض رسوم العيادة القادمة من API.
- عرض الطبيب والدوام عند اختيار العيادة.
- إنشاء حجز مؤقت + Clinic Invoice.
- عرض الفواتير المعلقة.
- رفع إيصال الدفع وإرساله للمراجعة.
- متابعة حالة الدور.

## ملاحظة

الواجهة تعتمد على Bootstrap من CDN في الوقت الحالي. قبل النشر على شبكة داخلية أو MikroTik بدون إنترنت خارجي، يفضّل توفير Bootstrap محليًا.


## شعار المستشفى

النسخة الحالية فيها مكان جاهز للشعار داخل:
`assets/images/`

الملف المؤقت المستخدم الآن هو `logo-placeholder.svg`. عندما يتوفر الشعار الرسمي، يمكن استبدال هذا الملف بشعارك بنفس الاسم (SVG)، أو تعديل مسار الصورة في `index.html` و`patient.html`.

يوجد أيضًا مكان جاهز لـ `favicon.png` إذا أردت استخدام نسخة مخصصة من الشعار بجانب اسم التبويب.
